Goal

Create an extremely minimalist, fast and precise floor plan editor that allows users to draw rooms with exact dimensions.

The tool should feel like a mix between:

Figma (simplicity + canvas editing)
AutoCAD (precision)
Notion (clean UI, no clutter)

No unnecessary UI. Everything must be extremely clean, white, and minimal.

🧱 CORE FUNCTIONALITY
1. Canvas (main workspace)
Infinite white canvas
Light grey grid (toggleable)
Zoom in / zoom out (mouse wheel)
Pan (space + drag or right click drag)
2. Drawing walls

User can:

Click to start a wall
Click again to finish it
Drag endpoints to adjust

Walls must:

Be perfectly straight (no curves)
Snap to angles: 0°, 45°, 90° (toggle optional)
Display real-time length (in meters or cm)

Each wall has:

Length label (editable manually)
Thickness (default: 10 cm, editable)
3. Precision system (VERY IMPORTANT)

When a wall is created or selected:

User can type exact length (e.g. 4.25 m)
The wall automatically resizes
Connected walls adjust intelligently if “lock joints” is enabled

Add a panel:

Input: length
Input: angle
Input: position (optional x/y coordinates)
4. Rooms detection

Automatically detect closed shapes:

If walls form a closed loop → create a “room”
Fill room lightly in grey (very subtle)
Show area inside (m²)
5. Doors & windows

Simple drag & drop system:

Door tool → click on wall to place
Window tool → click on wall to place

Rules:

Doors/windows must snap onto walls
They modify wall geometry automatically (cut wall segment)
Adjustable width (e.g. 80cm, 90cm)
6. Editing system

Click any object:

Wall → edit length, angle, position
Room → show area only
Door/window → resize, delete

Delete key removes selected element.

Undo / redo (Ctrl+Z / Ctrl+Y)

🎨 UI / DESIGN (VERY IMPORTANT)

The UI must be extremely minimal:

Layout:
Left: small vertical toolbar (icons only)
Center: canvas (90% of screen)
Right: properties panel (only when selection exists)
Style:
White background (#ffffff)
Light grey grid (#f2f2f2)
Black text only
No shadows
No gradients
No animations except smooth drag
Toolbar icons:
Select
Wall tool
Door
Window
Delete
Measure tool
📏 MEASUREMENT SYSTEM

Everything must support:

cm AND meters toggle
Real-time dimension display on hover
Permanent dimension labels on walls (toggleable)

Accuracy must be pixel-perfect:

1px must map to a real-world scale
Example: 1m = 100px (configurable scale system)
💾 DATA STRUCTURE

Store project as JSON:

{
  "walls": [
    {
      "id": "",
      "x1": 0,
      "y1": 0,
      "x2": 0,
      "y2": 0,
      "thickness": 10
    }
  ],
  "doors": [],
  "windows": [],
  "rooms": []
}

Autosave to localStorage.

📤 EXPORT

Add export options:

Export PNG (high resolution)
Export PDF with dimensions
Export JSON (for reload)
⚙️ TECH STACK (IMPORTANT)

Use:

React (or vanilla JS if simpler)
Canvas API OR SVG (SVG preferred for precision editing)
Minimal state management (no heavy frameworks needed)

Prefer SVG because:

easier geometry editing
better precision
easier selection system
🧠 BEHAVIOR RULES
No clutter in UI
No onboarding screens
No modals unless essential
Everything must be immediate
Speed > features
Precision > aesthetics
🧪 V1 SCOPE ONLY

Do NOT include:

3D view
AI features
collaboration
login system
cloud storage

Only local, fast, precise 2D editor.

🏁 FINAL GOAL

The app should allow a user to:

Draw a room in under 30 seconds
Enter exact dimensions
Adjust everything with precision
Export a clean architectural plan
